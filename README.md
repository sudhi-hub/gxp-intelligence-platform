GxP Intelligence Qualification Platform

An intelligent web-based platform designed to organize and track pharmaceutical equipment qualification and validation workflows in a GxP environment.

Features

* Overview Dashboard — View qualification progress and key metrics.
* Equipment Management — Browse and track pharmaceutical equipment.
* Qualification Workflow — Organize equipment qualification milestones.
* Document Library — Access qualification-related documentation.
* Review Workspace — Support document and workflow reviews.
* Audit Trail — Provide an interface for audit-related tracking.
* Reports — Present qualification information and summaries.
* Settings — Configure platform preferences.

Tech Stack

* React
* TypeScript
* Vite
* CSS

Getting Started

Prerequisites

Install Node.js and npm.

Installation

npm install

Run locally

npm run dev

Open the local URL displayed in your terminal.

Build

npm run build
